# E-Commerce Checkout QA Project

## Project Overview

This is a fictional e-commerce checkout project created to demonstrate software testing skills and QA methodology.

The project covers the complete checkout journey, starting from cart validation and checkout information through payment processing and loyalty features.

All scenarios, data, business rules, and test cases in this project are fictional and created for portfolio demonstration purposes.

## Testing Scope

The testing scope includes:

- Cart Validation
- Checkout Validation
- Payment Method Selection
- Credit Card Payment
- Payment Success & Failure
- Voucher
- Promo Code
- Loyalty Points
- Reward Combination
- End-to-End Checkout Flow

## Testing Approach

The test cases cover multiple testing perspectives, including:

- Functional Testing
- Positive Testing
- Negative Testing
- Boundary Testing
- Edge Case Testing
- Business Rule Validation
- Integration Testing
- End-to-End Testing
- Regression Testing

## Test Case Structure

Each test case may contain:

- Test Case ID
- Title
- Description
- Precondition
- Parameter
- Steps
- Expected Result

Test steps use a structured Given / When / Then format with `And` for additional conditions or actions.
